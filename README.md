# Pearl Dental Studio — Static Website Demo

A responsive dental clinic demo website built with HTML, CSS, and vanilla JavaScript. Intended as a showcase template for a one-time ₱10,000 website package.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. In Vercel, import that repository.
3. Framework preset: **Other**.
4. Build command: leave blank.
5. Output directory: `.` (project root).
6. Deploy.

## Demo content that must be replaced before a real client launch
- Pearl Dental Studio name and branding
- Sample dentist name, profile, and credentials
- Sample testimonial (fictional)
- Clinic address, schedule, phone, and email
- Appointment form email destination in `script.js` (currently demo address)
- Images and any service content to reflect actual clinic and permissions

The inquiry form is a front-end demonstration. It opens the visitor's email app using `mailto:` and does not save submissions. For real booking, connect a form provider or backend and update privacy messaging accordingly.
